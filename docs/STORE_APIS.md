# Исследование API магазинов для Opti

Повторная проверка: 2026-09-23.

## Короткий ответ

**Свободного публичного API «дай весь список товаров с ценами для сравнения» у Ашана, Магнита и Пятёрочки нет.**

При этом у сетей **есть API и каналы данных**, но они для других ролей (поставщик / продавец маркетплейса / платный партнёр аналитики), а не для стороннего прайс-агрегатора без договора.

| Вопрос | Пятёрочка (X5) | Магнит | Ашан |
| --- | --- | --- | --- |
| Бесплатный открытый API всего розничного каталога? | Нет | Нет | Нет |
| Есть ли вообще API/канал с товарами? | Да, для партнёров/поставщиков | Да, Seller API Маркета + внутренний backend сайта | Да, EDI для поставщиков |
| Подходит ли это Opti «из коробки»? | Нет, нужен договор | Нет для розницы; Маркет ≠ витрина магазинов | Нет, EDI — обмен с поставщиком |

## Пятёрочка / X5 Group

### Что есть официально
1. **Dialog X5 Analytics** — https://dialog.x5.ru/analytics  
   - В FAQ прямо: данные можно получать по **API**, Excel, PDF, **Data Bridge**.  
   - Доступ: бесплатные дашборды — зарегистрированным поставщикам; платные продукты — после договора с sales-менеджером.  
   - Даже не-поставщикам могут выдать доступ к части аналитики — но это **лицензия**, не open API.  
   - В оферте: «Справочник товаров» = атрибуты **товаров поставщика**, не полный публичный прайс всех SKU сети для любого разработчика.  
   - Публичных URL endpoint’ов / OpenAPI в открытом доступе **нет**.

2. **partner.x5.ru** — API/контент для **загрузки** карточек поставщика **в** X5 (через Brandquad и др.), направление «в сеть», не «каталог наружу».

3. **X5 DataBridge** — клиентское ПО с интеграцией к Dialog X5 API (новость X5, 2023). Снова партнёрский канал.

### Чего нет
- Публичного developer portal с ключом «зарегистрировался и тянешь 5ka catalog».
- Подтверждённого `api.5ka.ru/v1/products` (хост → 404).
- Открытого доступа к `5ka.ru/api/catalog/...` без антибота (из среды → 403).

### Неофициально
Сторонние библиотеки (pyaterochka-api и т.п.) эмулируют сайт. Это **не** официальный API и не правовой путь для продукта.

## Магнит

### Розничные магазины / magnit.ru
- Публичного developer API «список всех товаров розницы с ценами» **нет**.
- Backend сайта/приложения (`web-gateway.middle-api.magnit.ru` и аналоги) в открытых обсуждениях фигурирует как внутренний API фронта — **не документированный публичный продукт**.

### Магнит Маркет — официальный API есть
- Документация: https://magnit-tech.github.io/market-partner-api/  
- OpenAPI: https://github.com/magnit-tech/market-partner-api  
- Авторизация: `X-Api-Key` продавца.  
- Есть методы вроде:
  - `GET /api/seller/v1/categories`
  - `POST /api/seller/v1/products/sku/list`
  - `POST /api/seller/v1/products/sku/price` / `.../price/info`
- Назначение: управлять **своими** товарами, ценами и заказами на маркетплейсе.  
- **Не** выгрузка ассортимента всех розничных «Магнитов» для сравнения с Пятёрочкой/Ашаном.

### Магнит Пост
- API доставки/статусов заказов — не каталог FMCG-цен.

---

## Ашан (Россия)

### Чего нет
- Публичного REST/GraphQL API каталога `auchan.ru`.
- `api.auchan.ru` из среды недоступен; сайт за QRATOR.

### Что есть для поставщиков
- Обязательный **EDI** (Контур.EDI, Saby, EDIweb и др.): сообщения ORDERS, ORDRSP, DESADV, **PRICAT** (каталог/цены, которые **поставщик отправляет в сеть**).  
- Это B2B-обмен по договору поставки, не открытый API для агрегатора.

### Коммерческие посредники
Платные парсеры/фиды (Apify, Datica и т.п.) — не API самой сети.

## Итог для Opti

Чтобы получать списки товаров и цен легально, варианты такие:

1. **Договор с Dialog X5 / data-продуктом** (и аналогами у других сетей, если появятся) — платный партнёрский API/фид.  
2. **Коммерческий data-провайдер**, который лицензирует данные.  
3. **Своя база** (чеки, краудсорс) — без копирования каталога сайта.  
4. До этого — **демо-данные** в `src/data/offers.js`.

Неофициальный парсинг внутренних API сайтов в продукт **не подключаем**.

Точка расширения в коде: `src/lib/catalog.js` → `fetchAllOffers`.
