# Исследование API магазинов для Opti

Дата проверки: 2026-09-23.

Краткий вывод: **публичного открытого API каталога цен для Пятёрочки, Ашана и розничного Магнита нет.** Есть партнёрские API (поставщик / маркетплейс) и неофициальные reverse-engineered клиенты сайтов — последние нельзя легально встроить в продукт без согласия сети.

| --- | --- | --- | --- |

## Пятёрочка / X5

### Официально
- Портал поставщика: https://partner.x5.ru/
- Экосистема Dialog X5: https://dialog.x5.ru/
- API у X5 ориентирован на **поставщиков**: передача карточек товаров **в** системы X5 (через кабинет / контент-провайдеров вроде Brandquad), а не на выдачу всего каталога цен наружу любому разработчику.
- Утверждения вроде «`https://api.5ka.ru/v1/products` + Bearer» в SEO-статьях **не подтверждены**: хост `api.5ka.ru` отвечает 404.

### Неофициально
- Python-клиент [pyaterochka-api](https://pypi.org/project/pyaterochka-api/) / [Open-Inflation/pyaterochka_api](https://github.com/Open-Inflation/pyaterochka_api) явно помечен как **not official** и эмулирует браузерный доступ к сайту.
- В открытых учебных репозиториях упоминаются пути вида `/api/catalog/v2/stores/{storeId}/categories/{categoryId}/products` на домене `5ka.ru`.
- Проверка из этой среды: `5ka.ru` и `/api/catalog/v2/` → **403** (антибот).

**Для Opti:** без договора с X5 / лицензированного фида подключать неофициальный клиент нельзя.

## Магнит

### Розничный сайт / приложение
- Публичного developer portal для каталога розничных цен нет.
- Хост `web-gateway.middle-api.magnit.ru` из этой среды **недоступен** (сеть/egress); в публичных обсуждениях фигурирует как backend сайта (`POST …/v3/goods` и аналоги).
- Сторонние пакеты (`magnit-parser`, `magnit-pure-api`) описывают reverse-engineering мобильного/веб API — это не официальный продукт Магнита.

### Магнит Маркет (официально)
- Документация: https://magnit-tech.github.io/market-partner-api/
- OpenAPI: https://github.com/magnit-tech/market-partner-api
- Авторизация: заголовок `X-Api-Key` (ключ продавца в ЛК).
- Назначение: управление **своими** SKU, ценами, остатками и заказами FBS — **не** выгрузка всего ассортимента розничных магазинов «Магнит» для сравнения цен конкурентов.

**Для Opti:** Seller API полезен, только если Opti сам продаёт на Маркете; для агрегатора розничных цен — нет.

## Ашан

- Публичного API каталога `auchan.ru` не найдено (`api.auchan.ru` недоступен).
- Сайт отдаёт HTML через защиту QRATOR; прямой открытый JSON-каталог не обнаружен.
- На рынке есть коммерческие парсеры/фиды (Datica, Apify actors и т.п.) — платные посредники, не официальный API сети.
- Piloterr «Auchan Search» относится к **auchan.fr**, не к российскому Ашану.

## Реалистичные пути для Opti

1. **Партнёрство / лицензированный фид** у сетей или data-провайдера (легальный и стабильный путь).
2. **Пользовательские чеки / краудсорс** (как у части приложений сравнения цен) — своя база, без копирования каталога сайта.
3. **Оставить демо-адаптеры** (`src/data/offers.js`) до появления договора.
4. **Не встраивать** неофициальные scrapers сайтов сетей в продукт без письменного разрешения.

Точка расширения в коде: `src/lib/catalog.js` → `fetchAllOffers`.
