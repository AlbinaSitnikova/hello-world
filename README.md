# Opti

Сайт-агрегатор цен продуктов из **Пятёрочки**, **Ашана** и **Магнита**.

## Что делает

1. Загружает каталоги трёх магазинов (сейчас — демо-данные).
2. Сопоставляет одинаковые товары по **названию** и **производителю** (нормализация текста, бренды, токены).
3. Показывает товар с **наименьшей ценой** крупно и цены остальных магазинов мелким шрифтом.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, превью: `npm run preview`.

## Важно про данные магазинов

У сетей нет публичного открытого API каталога. В `src/data/offers.js` лежат реалистичные демо-офферы. Точка расширения — `src/lib/catalog.js` (`fetchAllOffers`): сюда подключаются партнёрские фиды или согласованные источники.
